# 脇本商会 / SoundAssist — WordPress テーマ

機材レンタル・映像制作&広告・輸入代理&正規代理店（DAS Audio 日本総代理店）の3事業を軸にした、プロオーディオ・システムインテグレーター向けのカスタムクラシックテーマです。ダーク基調にシグナルレッドのアクセント、ラインアレイをモチーフにした装飾で、信頼感と精密さを表現しています。

---

## 動作要件

- WordPress 6.0 以上
- PHP 7.4 以上

外部プラグインへの依存はありません（Contact Form 7 などはお好みで追加できます）。

---

## インストール手順

1. このテーマフォルダを ZIP 圧縮します（すでに `wakimoto-theme.zip` を同梱しています）。
2. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード** を開きます。
3. `wakimoto-theme.zip` を選択して **今すぐインストール** をクリックします。
4. インストール後、**有効化** します。

> FTP/SFTP で設置する場合は、`wakimoto` フォルダごと `/wp-content/themes/` 配下にアップロードしてください。

## 初期設定（推奨手順）

### 1. トップページをこのデザインにする
**設定 → 表示設定 → ホームページの表示** で「固定ページ」を選び、「ホームページ」に任意の固定ページ（例：「ホーム」）を指定します。これでトップに `front-page.php`（ヒーロー＋3事業＋DAS Audio＋お知らせ＋お問い合わせ）が表示されます。
※「投稿ページ」に別の固定ページ（例：「お知らせ」）を指定すると、ブログ一覧用のページになります。

### 2. メニューを作成する
**外観 → メニュー** で新規メニューを作成し、表示位置に以下を割り当てます。
- **グローバルナビ（ヘッダー）**
- **フッターナビ**

割り当てが無い場合は、固定ページが自動でヘッダーに並びます。

### 3. ロゴと基本情報
- **外観 → カスタマイズ → サイト基本情報**：ロゴ画像・サイトのタイトル／キャッチフレーズ。
- ロゴ未設定時はテキストのサイト名が表示されます。

### 4. 内容の編集（コード不要）
**外観 → カスタマイズ → 脇本商会サイト設定** から、以下をすべて画面上で編集できます。
- **ヘッダー**：電話番号・CTAボタン
- **トップ：ヒーロー**：英字ラベル・見出し（改行可）・本文・ボタン2つ
- **トップ：事業内容（6領域）**：6つの事業（コンサートオペレーション／製品販売　正規販売店／輸入代理事業／設備管理／機器導入コンサルティング／機材レンタル）のタイトル・説明・**写真**・リンクを設定できます。写真未設定の場合はプレースホルダ（PHOTO）が表示されます。
  - 「製品販売」の**リンク先（事業2：リンク先）**に EC サイトの URL を、「輸入代理事業」の**リンク先（事業3：リンク先）**に取扱ブランドサイトの URL を入力してください（初期状態は未設定のためボタンは表示されません）。
- **トップ：お知らせ**：見出し・表示件数（投稿から自動取得）
- **トップ：お問い合わせ CTA**
- **フッター・会社情報**：会社名・住所・電話・メール・コピーライト・SNS（X / Facebook / Instagram / YouTube / LINE）

### 5. ⚠ 連絡先のご確認
初期値として、電話番号 `0495-37-4806`・メール `info@wakimotocorp.com`・住所「埼玉県本庄市」を入れてあります。**郵便番号・番地以降はプレースホルダ**ですので、カスタマイザーで正しい住所に置き換えてください。

## お知らせ（投稿）について

トップの「お知らせ」は **投稿（Posts）** を新しい順に表示します。カテゴリーを付けると、各記事にカテゴリー名のバッジが表示されます。記事を投稿すると自動で反映されます（表示件数はカスタマイザーで変更可）。

---

## 固定ページのテンプレート

固定ページ編集画面の **ページ属性 → テンプレート** から選べます。
- **既定（サイドバーあり）**：右側にウィジェットを表示（ウィジェット未設定なら自動で1カラム）。
- **全幅（サイドバーなし）**：読みやすい1カラム幅で本文を表示。
- **業務内容（サービス詳細）**：コンサートオペレーション・設備管理・機器導入コンサルティング・機材レンタルの4業務を写真付きで詳しく紹介する専用レイアウト。

ブロックエディタの本文はテーマのタイポグラフィ（`.prose`）が適用され、見出し・引用・表・コードなどが整います。

### 業務内容ページの作り方

1. **固定ページ → 新規追加** で「業務内容」を作成。
2. **ページ属性 → テンプレート**で「**業務内容（サービス詳細）**」を選択。
3.（任意）本文にリード文を書くと、各サービスの上に導入文として表示されます。
4. 各サービスの写真は、トップの事業写真と共用です。**外観 → カスタマイズ → トップ：事業内容（6領域）** で対応する事業（コンサート＝事業1／設備管理＝事業4／機器導入＝事業5／機材レンタル＝事業6）の写真を設定すると、業務内容ページにも反映されます（未設定時は PHOTO のプレースホルダ）。
5. 各サービスのリード文・対応内容（箇条書き）を変更したい場合は、`template-services.php` 冒頭の `$services` 配列を編集してください。
6. ページ下部のお問い合わせ誘導は、トップと同じ「トップ：お問い合わせ CTA」の設定を共用します。

> 既存メニューの「業務内容」を、作成したこのページに差し替えれば完了です。

## 既存サイト（Elementor / WooCommerce）との関係

- 現在 Elementor で作られたページは、このテーマでも引き続き表示・編集できます。Elementor を使わずブロックエディタ／本テンプレートで作り直す場合は、各ページの本文を整えるだけで上記デザインが反映されます。
- レンタル（`rental.wakimotocorp.com`）等で WooCommerce を使う場合に備え、テーマ側で WooCommerce サポートを宣言済みです。本格的な商品ページのデザイン調整が必要な場合はご相談ください。

## デザインのカスタマイズ（任意・コード）

色やフォントは `assets/css/main.css` 冒頭の `:root` で一元管理しています。

```css
--accent:   #ff3a1f;   /* アクセント（赤） */
--ink:      #0c0d10;   /* 背景（ダーク） */
--paper:    #f3f1ea;   /* 明るいセクション */
--font-display: "Archivo", ...;          /* 見出し（英字） */
--font-sans:    "Zen Kaku Gothic New", ...; /* 本文（和文） */
--font-mono:    "IBM Plex Mono", ...;     /* ラベル */
```

この数値を変えるだけでサイト全体のトーンを調整できます。
